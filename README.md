# Fundaci-n-ARKHE

Arte · Memoria · Naturaleza · Tecnología · Comunidad

Volver al origen para construir futuro.

## Sobre la fundación

Fundación ARKHE es una iniciativa orientada a fortalecer comunidades y territorios desde la relación entre arte, memoria, naturaleza, tecnología y comunidad. Su propósito es aportar herramientas para la reflexión, la creatividad y la transformación social.

## Proyecto

Este repositorio contiene la landing page institucional de Fundación ARKHE, desarrollada en HTML y CSS puro para facilitar su visualización y personalización.

## Archivos

- `Fundación ARKHE.html` — Página web principal
- `README.md` — Documentación del proyecto

## Cómo visualizar la página

1. Descarga o clona este repositorio.
2. Abre el archivo `Fundación ARKHE.html` en tu navegador.
3. Si deseas, puedes publicarlo en GitHub Pages o en cualquier hosting estático.

## Objetivo

Crear una presencia digital clara, moderna y con una identidad cultural y territorial alineada con el propósito de la fundación.
